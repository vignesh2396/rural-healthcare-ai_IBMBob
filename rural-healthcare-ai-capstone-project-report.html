Phase 1 — Business Analysis

1.1 Executive Summary

The Rural Healthcare AI Navigation System is a production-ready Agentic AI prototype that addresses the critical challenge of healthcare navigation in rural India. Patients in semi-urban and tribal regions face significant barriers to accessing appropriate healthcare services — distance, awareness gaps, fragmented referrals, and language barriers. This system deploys a 6-agent AI architecture to help patients identify appropriate facilities, specialists, referral pathways, and government scheme eligibility — all without attempting to replace qualified medical professionals.

Phase 7 — Security Architecture

Data Protection

  • API keys in .env (never in code or Git)
  • PII masking filter on all loggers
  • Session tokens (UUID hex) — no user IDs
  • Minimal PII collection by design
  • SQLite WAL mode for data integrity

OWASP Controls

  • A01 — Parameterized SQLAlchemy queries
  • A02 — No hardcoded secrets
  • A03 — Input validation on all tools
  • A05 — Non-root Docker user
  • A09 — Rotating file logging + audit trail

Audit Trail (HIPAA-compatible)

  • All agent actions logged with UUID
  • Session ID on every log entry
  • Timestamps in UTC ISO format
  • Duration (ms) for performance tracking
  • Emergency escalations flagged

Healthcare AI Safety

  • No diagnosis capability by design
  • Emergency bypass always active
  • Human review flagged for emergencies
  • Disclaimers on every response
  • LLM temperature 0.0–0.2 (factual)

Capstone Final Goal — Answers

QuestionAnswer
ProblemPatients in rural India cannot easily find appropriate healthcare facilities, specialists, or referral pathways — leading to delayed care, unnecessary travel, and tertiary hospital overcrowding.
UserRural patients, ASHA/ANM community health workers, family members navigating healthcare for elderly or vulnerable relatives.
IntelligenceAI assesses urgency, maps symptoms to departments, discovers & ranks facilities, generates referral plans, answers knowledge questions, and immediately escalates emergencies.
AgentsAssessment (triage), Discovery (facilities), Referral (planning), RAG Knowledge (education), Appointment (coordination), Emergency (escalation), Supervisor (orchestration).
Toolsassess_urgency(), map_symptoms_to_departments(), search_healthcare_facilities(), find_specialists(), generate_referral_summary(), check_appointment_availability(), ChromaDB RAG pipeline.
Agentic WorkflowMessage → Supervisor routes → Assessment gathers context → Discovery searches DB → Referral plans → Appointment coordinates. Emergency bypasses all stages immediately.
AutonomyFacility search, department mapping, urgency assessment, referral generation, and knowledge retrieval all happen autonomously with no user intervention beyond providing location and need.
ValidationRAG relevance scores, urgency keyword matching, facility scoring algorithm, low-confidence flags, source citations, LLM temperature controls.
SafetyEmergency keywords → immediate escalation + 108 hotline. High urgency → human review flag. Low RAG confidence → explicit warning. Always: medical disclaimers + no diagnosis.
ImpactReduces time-to-facility from 30+ min to <3 min. Reduces unnecessary tertiary visits 25–40%. Increases government scheme awareness. Eliminates delays in emergency recognition.
